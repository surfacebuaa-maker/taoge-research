# 第114课：红盘率、涨跌家数（情绪、温度）

**本课最值得带走的思路：先判断市场给大多数股票提供了什么环境，再讨论具体个股的机会；观察红盘率时，要对准自己实际交易的股票范围。市场普涨时的盈利、普跌时的压力，都需要放回这个环境中理解。**

## 核心洞见

### 1. 红盘率把抽象的市场情绪，变成“上涨覆盖了多少股票”

**重点：市场温度可以落实为上涨覆盖面；小盘指数的强弱，则提供一个快速观察这种环境的入口。**

00:01—00:28，桃哥承接第113课，把“2000—平均股价—红盘率”连起来，希望用少数主要指标抓住共同的市场状态，减少重复统计。05:52—08:25，他展示两段历史样本，将中证2000涨跌幅排序，再对照红盘家数与比例，说明在所示样本里，两者有明显的同向关系。

视频里的第一组表标注为2023年12月1日至2024年1月15日；他又补入另一段样本进行合并比较。**这里值得学的是，把“今天好不好做”的感受，落到指数表现和上涨覆盖面的对应关系上。**

他在课中用下面的粗分档帮助建立直觉。这是课程经验示意，适合描述环境强弱，不能直接当作精确换算表或个人交易胜率。

| 中证2000当日涨跌幅 | 课中概括的全市场红盘率 |
|---|---|
| 约＋2% | 约九成 |
| 约＋1% | 约七至八成 |
| 约＋0.25% | 约六成 |
| 约－0.25% | 约四成 |
| 约－1% | 约两成 |
| 约－2% | 约一成 |

**我的理解：同样研究个股，上涨覆盖面广和上涨覆盖面窄，出发点完全不同。** 一个候选股看起来有理由，还要看它是在广泛修复中受益，还是需要独自抵抗整个市场的压力。判断“机会多不多”可以先于逐只解释“为什么它可能涨”。

### 2. 红盘率要匹配自己的交易范围

**重点：全市场还剩多少上涨股票，未必代表自己关注的小盘股还有同样多的机会。**

08:48—09:44及13:32—15:10，桃哥反复提醒，全市场红盘率包括银行、高股息等方向。这些股票有时在小盘走弱时相对坚挺，因此全市场仍有一部分股票上涨，自己关注的小票却可能更加普遍地下跌。小盘强势而防守方向偏弱时，也可能出现反过来的情况。

这与第111课的银行、红利分化，以及第112课的市值分类连在一起：**指标覆盖的股票范围，要和自己的观察池相匹配。** 如果研究小盘策略，全市场统计之外，还需要知道小盘样本和自己的候选池各有多少股票在涨。

**由此延伸：同一张日表中分别计算全市场、小盘样本、防守方向和候选池的红盘率。** 用实际分组看出差异，就能分清“市场仍有上涨股票”与“自己这一类股票的环境改善”是否同时成立。课程提出的扣除干扰思路，可落实为这样的分组统计。

### 3. 普涨时容易盈利，要分清市场贡献与选股贡献

**重点：同一套选股动作，在不同市场环境中可能得到很不一样的结果。**

10:37—11:57，桃哥用当时2月强势行情中“买了就容易赚”的感受作对照：当很多股票都上涨时，盈利覆盖面本来就广；如果预判小盘将明显走弱，仍随意挑几只股票参与，就是忽视了共同环境的影响。

15:37—15:50，他也提到极强主线或少数突出个股可能成为例外。他真正反复强调的是，不能把自己恰好选中例外，当成默认前提。

**我的理解：评价自己的选择，要同时保留当时市场和候选池的表现。** 普涨时做对一只股票，可以进一步比较它是否比同类候选更强；普跌时出现回撤，也要分清环境压力、标的选择和进出时点分别起了什么作用。这比单凭某几次赚亏判断一套方法是否有效，更有研究价值。

这条洞见也给第113课的候选池增加了用途：提前留下名单和选入理由，之后才能比较，而不只记住事后最强的几只股票。

### 4. “指数清了，后面谨慎”，表达的是对整个小盘环境的判断

**重点：一个操作表述背后，可能包含对行情阶段和后续个股机会的判断。**

16:01—17:59，桃哥回看自己2024年3月19日发布的“2000清了，后面出手谨慎点”，并解释：他认为前面的主升、补涨与题材切换已经走过一段，对后续继续上行的空间不乐观，因此开始重视小盘整体回撤的压力。

19:42—21:42，他又用随后几次明显下跌的日线回看这个判断。21:04—21:14的解释尤其直接：清掉指数，背后是“不看好当前平均股价继续往上走”；后面谨慎，影响的自然也包括小盘个股的选择与持有。

**我的理解：复盘作者操作时，可以把“做了什么”和“判断了什么”同时记录。** 卖出某个指数工具只是表面动作，研究上还要追问他当时认为市场处于哪个阶段、哪些机会将减少，以及什么变化会让他重新考虑参与。

本课提供了一个历史回看案例。后续研究要保留事前判断的时间和依据，再对照实际走势，才能检查环境判断是否有用。课程中的回看本身不等于已经验证了预测能力。

## 对实际研究的启发

第111—114课逐步把观察对象连接起来：行业和权重说明谁在推动行情，市值分类说明自己参与哪类股票，平均股价与小盘指数帮助观察整体变化，红盘率则把这种变化落到上涨覆盖面。

可以把本课的研究用途放进以下三项固定记录：

| 记录内容 | 需要回答的问题 |
|---|---|
| 市场与分组红盘率 | 广泛修复还是少数方向走强？我关注的股票群体处境如何？ |
| 事前的环境判断 | 当时预计行情改善还是转弱，依据和记录时间是什么？ |
| 候选池与实际结果 | 后续表现来自市场普涨、个股相对强弱，还是进出时点？ |

桃哥反对的是围着相近结果重复做大量统计。**由此延伸，基建可以保留必要的原始数据，用来校准和发现分化；日常查看时则突出少数真正影响判断的指标。**

## 简短补充

本课把关系讲得很绝对，其中“均值确定，红盘率就唯一确定”不能作为数学结论：分布形状和离散程度也有影响。红盘率通常相对昨收计算，也不等于按某个买点买入后的盈利比例。笔记保留其“重视共同环境、匹配交易范围”的洞见，经验数字用历史数据校准，极弱也不写成必亏。
