# 第112课：小市值策略线

**本课最值得带走的思路：先辨认股票的市值风格，再选择对应的观察指数。桃哥用中证2000抓小票行情，用少数代表指数压缩重复信息；同一个行业里的大票和小票，也可能走两种行情。**

## 核心洞见

### 1. 选小盘行情的代表，关键是它实际覆盖哪一层股票

**重点：名字里都有“2000”，背后的市值风格仍可能不同。桃哥选择中证2000，是因为他更看重较小市值股票的弹性。**

00:37—01:38，桃哥用课件中的市值分层示意，比较中证和国证两个指数系列。中证2000对应的股票层次比国证2000更靠后，整体更偏小市值；02:30—02:53，他由此给出本课的观察顺序：

> 课程中的弹性排序：中证2000 ＞ 国证2000 ＞ 中证1000 ＞ 中证500。

他想传达的是：如果研究目标已经确定为小票行情，观察对象就应尽量贴近这种风格。05:39—06:01，他进一步指出，同时买中证500、中证1000、国证2000和中证2000，在他的框架中没有必要，因为这些工具都被拿来表达相近的中小盘判断，而弹性又有差异。

**我的理解：先写清想研究哪类行情，再选最有代表性的工具。** 多看几个指数可以用于比较，但不能仅凭名称不同，就认为获得了几份独立信息，或做了几种不同的布局。这里的“弹性”应连同上涨和下跌两面一起观察。

### 2. 指数包含的股票更多，主导力量仍可能是同一批大票

**重点：成分股数量增加，并不必然改变指数主要受谁推动。**

02:55—04:20，桃哥解释中证800、国证1000为什么在他的看盘框架里仍属于大票方向：其中包含的大市值公司影响很大。03:45—04:10，他把上证50、中证800和国证1000叠在一起，展示走势主线相近的区间，用来支持“减少重复研究对象”的思路。

这一点与第111课的行业ETF洞见相通：理解一个工具，既看它装了哪些股票，也看谁的影响最大。多放进几百家公司，未必能显著改变头部公司的主导作用。

**由此延伸：整理自选时，可以同时检查成分权重和同区间走势。** 如果几个指数长期提供相近信息，可以留一个主观察对象，其他作为比较参照；出现分化时，再追查行业构成和权重变化。这样既能简化看盘，也能保留发现差异的入口。

本地配图：[视频04:00，上证50、中证800、国证1000叠图](../课程视频/112_分析素材/0400_大盘指数叠图.jpg)（仅本机可看）。

### 3. 同属一个行业，大票和小票也可能走两种行情

**重点：行业归属之外，还要加上市值风格，才能更好地理解一只股票在跟随什么。**

05:19—05:38，桃哥专门用新能源作提醒：宁德时代等几十只核心大票，更体现行业核心赛道自己的走势；新能源小票则更受小盘整体行情影响，他用“跟2000”概括这种联系。

这是本课与第111课最值得连起来看的地方。第111课说，行业ETF主要由行业大票推动；第112课补上，小票即使挂着同一个行业标签，也可能更多地跟随小盘行情。因此，看到几只新能源小票活跃，不能直接据此判断新能源核心大票或行业ETF同样走强。

**我的理解：研究底表应同时保留“行业”和“市值”两条分类。** 比较一个行业时，把核心大票、活跃小票和中证2000放在同一时间区间，才容易分清这次变化主要来自行业走强，还是小盘整体修复。个股的题材与事件影响再单独记录。

### 4. 观察基准可以更新，背后的研究目标保持一致

**重点：真正需要持续跟踪的是小盘风格；哪个指数最适合代表它，可以随着市场结构变化而调整。**

01:41—02:35，桃哥解释为什么前面的课常用国证2000，而这一课更强调中证2000：早期讲课时还没有中证2000，后来指数和股票数量发生变化，便有了更贴近他观察目标的工具。他还据此设想，以后股票继续增多，可能出现新的代表指数。

这条思路的价值在于，工具选择要能说明理由。不能因为一直看某个指数，就把它永久当作同一类行情的最佳代表。

**由此延伸：自选清单和研究底表要记录纳入理由、数据日期和调整记录。** 更新代表对象时保留旧口径，方便分清究竟是市场风格变了，还是自己换了观察尺度。

## 对实际研究的启发

把第111、112课连起来，可以形成下面的观察顺序：

| 研究对象 | 优先厘清的驱动 | 本课带来的补充 |
|---|---|---|
| 蓝筹及大盘宽基 | 主要权重公司、行业构成 | 检查上证50、沪深300、中证800、国证1000是否提供重复信息 |
| 新能源、科技等行业核心大票 | 行业趋势及核心公司的表现 | 延续第111课的赛道观察；上证50不能包办所有大市值方向 |
| 广泛的小票行情 | 小盘整体强弱与市值弹性 | 桃哥在本课优先用中证2000作代表 |
| 同行业的具体股票 | 行业归属、市值风格及自身事件 | 把核心大票与小票分开比较，确认实际跟随关系 |

核心研究链条是：**辨认行情驱动 → 选择对应代表 → 比较实际走势 → 检查所选工具是否表达了原来的判断。**

### 1. 给指数底表补上市值画像，形成有依据的自选分组

- 解决的问题：分清中证、国证系列实际偏向哪类股票，判断哪些观察对象重复。
- 范围与字段：在已有主要指数资料上补充中证500、中证1000、国证2000、中证2000的成分股市值中位数、加权平均市值、前十大权重占比、行业分布、数据日期及市值口径；自选去重时同时比较上证50、沪深300、中证800、国证1000。
- 具体成果：指数行业与市值画像表，以及带选择理由的主观察、辅助比较清单。
- 完成标准：能用同一日期的数据说明各指数主要代表哪类股票，并给出每个观察对象保留或合并的依据；保留以后调整代表对象的记录。
- 来源洞见：第1、2、4条；课件第5—6页。关联总TODO第2、5项。

### 2. 给行业观察池补上大小盘标签

- 解决的问题：避免把行业小票活跃误认成核心大票和ETF同步走强。
- 范围与字段：先从新能源开始，记录行业、总市值及日期、ETF权重、核心大票或小票分组；另记题材、事件与选入理由。
- 具体成果：能按行业和市值交叉筛选的股票观察池。
- 完成标准：每个先行覆盖的行业都有大票、小票两组可比较样本，分组口径一致，能够回查数据来源。
- 来源洞见：第3条，视频05:19—05:38。关联总TODO第4项。

### 3. 在趋势对照图中加入小盘梯度与同行业大小票比较

- 解决的问题：把“更有弹性”“跟随行业还是小盘”转成可查证的走势比较。
- 范围与字段：同一起点归一化展示中证500、中证1000、国证2000、中证2000；另比较新能源核心大票、小票样本、行业代表工具与中证2000。固定样本及比较区间，记录区间涨跌幅和最大回撤。
- 具体成果：可重复更新的两组对比图及样本说明。
- 完成标准：至少覆盖一段共同上涨和一段共同下跌区间，能辨认相对弹性及行业内大小票分化，避免只挑上涨片段。
- 来源洞见：第1、3条。关联总TODO第7项，典型分化案例沿用第9项保存。
