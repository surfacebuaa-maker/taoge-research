## 这轮回答一个问题

普通主板情绪连板股票连续一字跌停后，在首日开板出现完整5分钟收盘确认时参与，下一交易日早盘计划退出，能否在可解释的成本及成交约束下得到稳定的正收益？

这是研究者对课程的可执行代理，不能直接称桃哥原样买卖。既有2024命名案例是发现与程序核查材料；旧试验与其他分支分别保留。尚缺可复算来源的旧试验线索集中列在文末，不作为已确认结果引用。

## LD-OPEN-01协议草案

| 事前候选 | 昨日OHLC全部等于当日跌停价，至少连续1个交易日；以这一段的首个一字跌停日为锚点，只回看其之前15个交易日，最大连续收盘涨停数至少3日。一字序列延长时不移动该锚点，沿用既有研究的情绪连板价格代理 |
| 原代理的漏选 | 神驰等不满足3连板代理的课程命名案例独立保留；本轮不为覆盖作者而临时放宽 |
| 研究事件 | 一段连续一字之后的首次开板日；连续一字的每个观察日仍在底表，不能只记录最终打开的赢家 |
| 入场信号 | 首根完整5分钟收盘价高于当日跌停价，最晚14:30确认；竞价打开也等该根完成 |
| 入场价格 | 信号完成后下一根预定5分钟开盘作价格参考；该根缺失或开盘处于涨跌停时记执行未确认，保留事件且不追选后续更好价格。该根最终高低价、成交量和成交额不参与开盘时的入场选择 |
| 仓位路径 | 每事件只初始买入一次，次日计划退出；本轮不加仓、不做T、不重复抄同一事件 |
| T+1退出 | 次日09:30为预定退出时点。该时点缺有效价格或处于跌停时记退出受阻，按后续预定5分钟开盘逐次检查，记录首次可核对的非跌停价格参考；不依据这些根最终的高低价或量额回选执行时点。有价格参考仍不等于已证明排队或指定数量可成交 |
| 跨日与终止 | 次日整日仍未确认退出时，继续逐交易日记录持仓、受阻原因及按同一规则检查的价格参考，直至退出或该研究段预先冻结的最后交易日。期末仍未退出的，以当日可核对收盘价列毛浮动收益；缺价则列估值未知，不补零、不伪造平仓净收益 |
| 成本 | 新方案拟按毛收益减往返总成本0.30个百分点（30基点）为基础情景、0.60个百分点（60基点）为压力情景，均待实现。另核验对应时期最低佣金、印花税和实际冲击，不称固定值为实际收费 |
| 容量 | 固定1万元为研究示例；整根成交额1%只生成事后容量诊断字段，不删除事件、不改变入场参考或退出时点，也不将无法验证成交的事件计成已成交。执行可确认性与容量诊断分别输出 |
| 其他特征 | 相对竞价金额、历史换手、队友、风险事件、前排依据先存原值与来源；本主版本不依据已看结果增删门槛 |

### 与现有程序的衔接及实现验收

现有程序的 `execution_issue()` 会返回 `capacity_unconfirmed`，据此阻断入场或推迟退出；它实际使用了整根成交额，不是只输出诊断。其净收益字段为 `net20_pct`、`net50_pct`、`net100_pct`，对应20／50／100基点；退出检查只覆盖下一交易日。上述旧行为及旧结果保留为探索记录，不冒称已经实现本方案。

新实现须将信号、预定价格参考、成交可确认性、数据质量和事后容量字段分开。仅有5分钟OHLC时，开盘参考及单一价、无量等事后标记只支持价格情景；实际成交证据不足的，继续列执行未确认，不纳入已核验策略收益。不能用事后容量合格与否筛选一个更好看的收益分母。

实现验收至少覆盖：保持开盘前信息及后续各根开盘价不变，只扰动执行根最终量额，预定入退场时点及价格参考不得改变，容量诊断可随之改变；新成本字段能从毛收益重算30／60基点情景；次日无法退出的事件能跨日保留，期末估值、未知状态和已退出收益分别可复算。实现、数据修复和验收完成后，再封存源码、协议、成本、研究段终止日期及输入哈希，开始独立验证。

## 三份依次验收的成果

### 1. 先把数据闭环做完

先复用现有14只课程股票、11段序列，逐日输出日线、分钟汇总与交易日历的差异清单，定位到入场与退出需要的那根价格。通达信240个分时点只有采样价格，不提供完整分钟OHLC，不能代填分钟最低。存在争议只暂停受影响事件的收益统计，同时报告排除比例及方向，避免剩余样本选择性变好。

交付：数据覆盖清单、争议修复记录、11段逐根时间表及通过上节验收的新实现。能从原始数据重算每项信号与参考执行；缺资料的明确到供应商、日期、字段。优先解决分钟价格和交易资格，历史封单不是本主版本的先决字段。

### 2. 按冻结规则扩展到完整候选

计划窗口：2023-01-01—2024-12-31用于开发与数据检查；2025-01-01—2025-12-31预留作历史验证。运行前核查项目以往是否已经用2025结果改过同类规则；若用过，就降为发现材料，另冻结未用于开发的新日期。2026已观看视频样本只作动作对照，不自动称未见样本。

完整扫描窗口内全部历史合格股票，包含退市对象与无触发日。若只拿到课程命名名单，交付应明确是名单回放，不能宣称全市场验证。各阶段保存候选总数、数据缺失、持续封死、触发、放弃、成交未确认及退出受阻，不能只展示成交样本。

交付：逐事件明细、基础及压力成本结果、逐月分布、持有期间最大不利波动、最差个案、跌停退出受阻天数。已退出净收益、期末未退出的毛浮动收益及估值未知事件分别列数量、分母和结果；只计算已退出者的均值时须明确覆盖范围，不能据此宣称全体事件盈利。具备完整执行证据后，再报告相应等权事件收益及交易日聚类的不确定性；组合年化、夏普和资金回撤待仓位占用与并发规则另行冻结后计算。

### 3. 独立日期连续模拟

冻结版本后，从下一个实际完成数据接入的交易日开始，连续记录至少20个交易日，连同零候选日一起保存。若事件很少则延长，不为凑交易改条件。原程序输出、实际可见时间和模拟成交状态同时归档；现有监控是否部署不等于本研究已经开始前向记录。

第一份历史结果目标至少100个合格事件、验证段至少30个事件；这只是初步覆盖目标，达到数量不代表统计充分。样本较少时报告“证据不足”，不凑成高胜率。

## 怎样判定结果值得继续

- 验证段基础成本下均值为正，压力成本下不明显反转；检查按交易日聚类的区间，区间仍跨零则不能确认优势。
- 收益分布、最差事件和退出受阻可解释；正收益不能只由一两笔或单一行情月份贡献。
- 同一冻结版本在不同阶段能重现，数据缺失与未退出样本全部披露，不能靠删除它们改善结果。
- 未通过时保存失败版本，再决定有机制依据的下一项试验。先核查数据、入场成本、隔夜跳空和退出损耗，不同时搜索一批金额、跌幅、时长参数。

后续动作补证重点是公开视频中能事前认定“核心／后排、为什么不买”的对照解释，供独立筛选研究；不要求补造作者未展示的精确成交图。数据抓取、复算和程序实现按上述验收流程推进。
