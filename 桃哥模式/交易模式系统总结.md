# 桃哥课程模式总结：先判断环境，再选择机会与工具

[研究首页](README.md) · [课程模式与案例映射](课程模式与案例映射.md) · [逐课笔记](../课程笔记/README.md) · [K线对照资料](K线与操作对照.md)

**这套总结从第111—127课出发：先区分大市值行业与小市值整体两条观察线，再判断机会是广泛修复、主线核心，还是依赖特定事件和交易结构。买入动作、持有安排和仓位服务于前面的判断。**

正文先写课程思路与课堂案例，随后才用B站操作和实际K线对照。原先按视频归纳的模式子文件夹已删除。这里整理为三条主线和三个专题研究单元；环境观察与执行管理单列，不把它们当作额外的交易模式。

**原完整索引覆盖至2026年10月16日；10/19—23另新增5条动作核对，见[增补](作者动作增补_20261019-23.md)，尚未重编原索引计数。** 本次新增9/21—10/16的13条公开投稿；资料池共73条、71个日期，累计重点核对41条。K16—K19四组之后，10月18日补充K20低空股债同步分钟案例及候选扩展，现合计19组案例、29张本地图。逐条来源与片段见[最新补录](视频更新_20260921-20261016.md)。

## 一、共同前提：环境判断先于具体买点

### 1. 先确认正在观察的股票群体

[111课00:18—04:24](../课程笔记/111_大市值策略线.md)把蓝筹、新能源、科技及红利等方向分开；[112课05:19—05:38](../课程笔记/112_小市值策略线.md)进一步区分同行业大小票；[127课01:02—05:12](../课程笔记/127_标的方向与容量选择.md)重申，小盘的整体框架不能直接解释所有容量方向。

因此，指数上涨之后要先问谁在推动、持仓属于哪一边。大票行业趋势、小票普遍修复和少数核心走强，分别进入后面的C01、C02、C03。

### 2. 月份、位置、成交与压力要连起来看

[117课00:26—02:10](../课程笔记/117_一年第一阶段行情规律.md)用2022年4月底、2023年10月底及2024年2月说明，月度净结果会遮住月内路径。[118课05:52—08:44](../课程笔记/118_一年第二阶段行情规律.md)强调相近参与氛围下，已有位置会影响空间；[126课04:30—06:56](../课程笔记/126_环境适应与回撤心态.md)把位置、参与氛围与成交联系起来。

[120课06:16—15:48](../课程笔记/120_一月极弱回顾.md)则提供完整的压力过程：短修复后出现新压力，原反弹预期落空，较大指数先改善，小票压力后来才变化。[123课15:14—25:12](../课程笔记/123_高低位极弱与压力判断.md)补充，已有跌幅和事件变化也可能使压力不再按旧路径扩散。

**据此整理的观察顺序：股票群体 → 位置与已有空间 → 成交和参与氛围 → 压力是否持续、扩散或解除。** 月份保留为课程的历史比较背景，不替代实际状态。

### 3. 指标用于辨认环境与分化

[114、115课](../课程笔记/114_红盘率与涨跌家数.md)区分上涨覆盖面与局部涨停端；[124课06:20—15:16](../课程笔记/124_统计偏离与情绪指标.md)说明温度回升可能只是跌得慢一些，价格仍未止跌。

观察时要保留样本、指标含义与价格路径。情绪统计描述当时环境，个股交易盈亏还取决于实际买价、隔夜及退出，不能直接互换。

## 二、C01：大市值行业与容量选择

**课程起点：行业工具主要受核心大票推动，方向自身的趋势和资金条件会影响它能否受益。** 主要依据为[111课](../课程笔记/111_大市值策略线.md)、[112课](../课程笔记/112_小市值策略线.md)和[127课](../课程笔记/127_标的方向与容量选择.md)。

### 课程怎样展开

111课05:13—06:42解释行业ETF与行业大票的关系；07:06—07:53比较新能源车与国证2000：市场修复可以暂时带动原先弱势行业，却未必改变其行业趋势。05:18—05:52又把旧赛道放在红利、新赛道及资金竞争中比较。

127课02:54—05:12把容量内部的成长、红利等分开；08:58—12:04用2023年7月及2024年9月的政策后行情，比较较宽容量工具与直接受益的行业工具。课堂重点是判断与工具匹配。

| 环节 | 从课程能够整理出的内容 |
|---|---|
| 适用环境 | 行业或容量方向自身出现参与依据；观察位置、流动性、催化与其他方向的竞争，不直接套小盘月份框架。 |
| 对象选择 | 先定成长、红利、金融或具体行业，再核对宽基、行业ETF及核心公司的权重与驱动。 |
| 参与判断 | 说明机会来自行业趋势、容量风格还是政策受益，选择能表达该判断的对象。课程没有给出跨品种统一的日内买点。 |
| 持有与退出 | 持有理由仍围绕该方向的驱动和趋势。原驱动改变、工具不再对应判断，是研究时应检查的变化；这几课未给出统一持有天数或止损幅度。 |
| 失败边界 | 由小票热闹推定行业ETF会涨；由小盘修复推定原弱势赛道会反转；假定容量方向同涨同跌；政策判断与实际受益工具错配。 |

**B站与K线对照的位置：** 新增9/29的00:26—00:50有因亨通容量偏大而选择通鼎的自述，是容量约束的局部线索，实际买的仍是较小对象；10/12有银行与创业板的分化观察。[K19药明与权重ETF](K线与操作对照.md#k19)再说明，ETF尾盘放量和行业个股受冲击可以同时出现，资金身份不由成交量直接确认。这些补充方向与工具比较，尚未建立成长、红利、政策容量的完整交易链。容大K11也只作工具切换和转强参与的局部讨论。

<a id="c02"></a>

## 三、C02：小市值整体修复

**课程起点：研究普通小票的共同环境，先判断整体修复，再选择对应代表及弹性。** 主要依据为[112课](../课程笔记/112_小市值策略线.md)、[113课](../课程笔记/113_平均股价＝2000.md)、[117—121课](../课程笔记/120_一月极弱回顾.md)、[123课](../课程笔记/123_高低位极弱与压力判断.md)。

### 课程怎样展开

112课00:37—02:53用市值分层解释中证、国证系列及小盘弹性；113课将平均股价、小盘代表和具体选股连接起来。117—119课要求把自然月与阶段拆开；120课以2024年1月底至2月的压力变化说明，已经跌很多、到了某一天、某个大指数翻红，都不足以单独证明小票风险解除。123课再要求比较起点位置和压力的实际作用。

| 环节 | 从课程能够整理出的内容 |
|---|---|
| 适用环境 | 普通小票经历共同下跌，前期空间、压力源和参与条件发生有依据的变化；区分整体修复与局部强股。 |
| 对象选择 | 使用已确认风格的小盘代表或有事前依据的候选。指数、ETF和个股不是同一个对象，行业退潮股也未必跟随。 |
| 买入观察 | 记录压力对象是否打开、承接能否延续、是否有新压力、上涨是否扩散。高低位与此前跌幅一并考虑，不只数跌了几天。 |
| 持有与退出 | 研究完整的压力、解除、修复及转弱过程；修复后的梯队和价格变化也会改变继续持有的依据。个股与指数工具可采用不同的持有安排。 |
| 失败边界 | 旧压力未稳又出现新压力；指数改善没有传到目标股票群体；抢跑后修复预期落空；把后来反弹用来合理化之前无限补仓。 |

**后续操作对照：** [K04／K14德明利与563300](K线与操作对照.md#k04)用来检查压力观察、具体工具、持有和减仓。7/21后并未一路上涨：563300到7/30收盘较7/21收盘回落4.71%，后来才进入连续阳线的一段。该路径限制了对“整体修复”的简化解释；作者低成本自述也不能替代不同买点的持有体验。

B站8/7关于首阴后看反包、8/14关于空间及反包的判断，是这组操作的补充证据；它们单独标为公开视频表达，不倒写成112、113课已经给出的固定退出公式。

**新材料对压力条件的限制：** [K17](K线与操作对照.md#k17)保留10/8观察源杰、10/9云南与东山反抽、10/12再跌及10/13再次修复。压力对象不再跌停，仍需检验传导、群体和持有路径；这批是科技方向材料，不能直接用来证明全部小票已经转强。10/14从“连跌”到“涨跌交替”的表达也仍是当时企稳假设。

## 四、C03：主线核心与当前预期

**课程起点：整体机会有限时，研究额外驱动仍在的方向和核心；买到曾经的强股，不代表买到当前仍有预期的对象。** 主要依据为[115课](../课程笔记/115_涨停数与封板率等.md)、[116课](../课程笔记/116_几个例子.md)、[119课](../课程笔记/119_一年第三阶段行情规律.md)、[121、122课](../课程笔记/122_环境对手法的影响与独立结构.md)。

### 课程怎样展开

119课00:14—08:16从2020年券商、2021年新能源，讲到赛力斯、华力创通等核心：行业强、核心强和全市场普涨应分别观察。116课09:01—10:56用掌阅科技与国证2000的分化，讨论原先题材预期已兑现后，不再适合直接表达小盘修复。122课10:46—18:38对照克来、艾艾与联明，把个体高度放回所处环境及队友中理解。

| 环节 | 从课程能够整理出的内容 |
|---|---|
| 适用环境 | 局部主线或个体有独立驱动；普通周期中机会可能集中，整体改善时也要区分核心与后排。 |
| 选股逻辑 | 先写当前预期、消息或事件依据、核心地位及板块带动性，再比较位置和相对强弱。股票熟悉、跌幅大、过去涨过都不能单独构成理由。 |
| 买点理解 | 急跌、分歧与消息后的跟随是表达机会的动作；需核对买入成本与当前预期。课程没有给所有核心股统一的跌幅或追价线。 |
| 持有与退出 | 检查预期是否兑现、队友与板块是否继续支持，按真实持有区间评价。消息抬高买价后，不能忽略收盘、隔夜与次日压力。 |
| 失败边界 | 原有预期消失、核心转为退潮或补跌、选到后排、板块不再承接、消息只带来短时拉升、隔夜预期反转。 |

**后续操作对照：** [K05创业黑马与传智](K线与操作对照.md#k05)检查个体急跌与队友强势的关系；[K03上海港湾与巨力](K线与操作对照.md#k03)、[K13火炬](K线与操作对照.md#k13)检查同题材选股与补涨预期；[K06康泰](K线与操作对照.md#k06)保留消息首日强势后隔夜转亏的反例。它们帮助检验C03的不同环节，不再分别生成“低吸”“轮动”“消息”等模式目录。

[K16新华医疗与新华都](K线与操作对照.md#k16)新增9/21参与、9/22兑现、监管与后排转弱，以及9/24再次参与后的行情。它补充的重点是：同名跟随需要自己的预期、容量和退出依据，不能把名称相近等同实质受益。10/13消息跟随未延续、10/14部分持仓格局过头，也使“当前预期”必须与实际持有区间相连。

**事件催化与强度传递补充：** [K20](K线与操作对照.md#k20)将10/16上工的题材跟随与保隆股债分开。10:00—10:30保隆、万丰已在涨停附近，保隆债仍只涨约1.6%—1.8%；之后债加速，午后又在正股仍封板时回落。可研究“消息发现方向—板块确认—工具尚有空间”的链条，股票熟悉或债涨幅小都不能单独成为买点。完整适用条件、两种参与分支与失败条件见[低空经济股债联动案例](低空经济股债联动_20261016.md)；这是一组候选机制证据，未证明完整选股排序或长期有效性。

[同日候选扩展](低空候选筛选_20261016.md)补24股、7组有效股债，按事前公司资料与盘中完成线分开核对主题资格和价格信号。保隆、万丰保留为强度信号，不因封板难买而剔除；未触发、外围待证及广泰触发后未获利均保留。公社“技术同源”的映射不能升级为新Roadster独家供货事实，产业关联也不等于当时具备参与条件。

本例还应记录**早封与板块扩散的先后**：保隆先响应事件，队友随后走强，使其事件核心地位和次日更强预期得到助攻。当前预期会随盘面新增信息变化，不能只把题材关联和当前涨幅作为静态标签。具体股债执行见C06。

## 五、C04：事件冲击后的开板与承接

**课程起点：同样是跌停打开，事件类型、位置、打开时间及环境不同，后续路径也可能不同。** 主要依据为[122课19:16—26:58](../课程笔记/122_环境对手法的影响与独立结构.md)和[123课](../课程笔记/123_高低位极弱与压力判断.md)。

122课用卓朗科技、青海春天、标准股份、天永智能、神驰机电等比较低位事件冲击与高位连板失败，也比较竞价、较早和较晚打开。123课再区分现实事件、压力源、整体传导，以及政策变化后没有照旧剧本继续扩散的情况。

| 环节 | 从课程能够整理出的内容 |
|---|---|
| 适用条件 | 能说明事件、已有位置和压力背景，观察风险是否仍在被重新定价；需要区分普通股与特殊状态对象。 |
| 对象与参与 | 记录事件预期、前期下跌、打开方式、成交及承接；打开本身不是充分条件，不能把所有地板归成同一种机会。 |
| 退出与失败 | 看回封、次日竞价与可兑现性；持续卖压、新风险、没有延续的反抽、高位失败与环境转弱都需重新评价。课中未给出通用止损百分比。 |

**后续操作对照：** [K09沐曦](K线与操作对照.md#k09)是已知事件落地后放量修复、作者明确未买的观察；[K10摩尔](K线与操作对照.md#k10)保留初次修复后再弱、卖后接回仍失败；[K12瑞尔特](K线与操作对照.md#k12)保留事前排除高位一字结构。解禁是视频里出现的事件实例，具体公告及可售数量尚未全部重建，不能将其扩成课程已经证明的“解禁必涨”规则。

[K18星网宇达与国恩](K线与操作对照.md#k18)补充10/15低吸、10/16先退出的两日自述。两股低位修复后次日高开，但收盘方向不同，支持继续区分参与价、兑现窗口和持有安排。具体公告、数量与精确买卖时点尚缺，不由最高反弹幅度重算作者收益，也不把月份变成固定胜率。

**情绪一字与突发利空分支分别研究：** 突发利空、非一字跌停的承接，与情绪连板股连续一字后的打开分组记录；情绪股叠加新公告时另保留事件标签。[情绪股开板专项](情绪股一字跌停后的开板研究.md)已按前一天观察、当天参与、次日退出重建标准、天永、神驰及联明、春光等11段序列。课程的高位弱环境警惕仍作为参与约束，不将“预计能开”直接升级为买点。当前日线事实可重算，历史封单缺失且分钟有争议，不能给出盈利有效性结论。

## 六、C05：尾盘成交结构

**课程起点：作者将尾盘承接与盘中打开后可能回封的情形分开，讨论价格反应留到下一交易日的可能。** 依据为[122课00:08—10:24](../课程笔记/122_环境对手法的影响与独立结构.md)。

课堂主例是2024年4月3日ST汉马，并比较ST泛海、ST天沃、贤丰和博信；作者还用博信说明公告风险可能使其放弃。课程关注成交相对剩余卖压的大小、时点及次日兑现，06:24—07:26讨论动态分组如何降低观察负担。

| 环节 | 从课程能够整理出的内容 |
|---|---|
| 适用条件 | 特定尾盘时点、真实承接、剩余卖压和具体公告状态共同构成情境。 |
| 参与与兑现 | 研究是否实际成交、是否真正打开、次日竞价可卖量与价格；提醒工具只用于发现候选。 |
| 失败边界 | 无法成交、卖压没有消化、公告改变条件、次日缺承接或无法退出。作者的“必赚”说法不作为研究结论。 |

**B站证据状态：** 8/5有尾盘特殊状态股票的操作线索，但尚未补齐公告、订单及次日退出链，因此只记录部分对应，不写成已完成验证。金健压异动依赖另一组条件，不因为同样发生在尾盘就归入C05。

## 七、C06：股债联动与转换

**课程起点：转债既可能依赖正股及板块，也可能涉及特殊相对价格与转换条件；两者应分别研究。** 依据为[122课27:04—32:38](../课程笔记/122_环境对手法的影响与独立结构.md)、[125课](../课程笔记/125_岭南转债与股债折价案例.md)、[127课13:04—15:18](../课程笔记/127_标的方向与容量选择.md)。

| 分支 | 课堂案例与推理 | 参与、兑现及失败检查 |
|---|---|---|
| 日内联动与隔夜预期 | 122课比较芙蓉、利民相关转债，说明正股当天封板仍可能被队友次日低开影响。 | 区分收益来自日内跟随还是次日更强；看正股、转债、队友、流动性与实际退出，不把封板自动连到隔夜获利。 |
| 相对定价与转股 | 125课01:30—05:58比较岭南正股及转债不同步下跌；06:02—09:24讨论价差变化和转股选择。 | 保存同一时点价格、转股价值、申请与到账及可卖时间；正股继续跌、价差扩大、信用与退出约束都可能破坏兑现。 |

125课09:38—10:46展示的后来成交与拉升，只能核对部分价格现象；资金是谁、为何买入需要独立证据。负溢价也不是已经实现的利润。

**B站证据状态：** 原7/2记录主要是工具讨论；9/29继续讨论转债工具。新增[10/16的00:28—00:48](https://www.bilibili.com/video/BV1wNJ96MEFu/?t=28)把保隆正股较早封板、次日一字预期和转债拉升联系起来，并提到其后大盘跳水，能与122课的日内和隔夜依赖作对照。这里是观察，未见本人明确买债。10月18日已补齐本例正股、转债与同方向股票的同步5分钟价格，并以转债1分钟线核对视频10:42光标；[K20](K线与操作对照.md#k20)保留先滞后、后加速及正股仍强而债回落的路径。作者真实债券成交、完整盘口和125课转换分支仍缺证据。白银LOF的净值与场内价格是另一套工具机制，不直接并入本专题。

### 早封核心的次日一字预期在当日债价中重估

**桃哥在10/16视频00:30—00:40明确解释：保隆在板块内较早涨停，资金预期次日可能一字，于是拉升转债。** 对应课程122课27:04—32:38的正股、债及队友依赖，可归纳为：正股抢先封板→板块扩散强化核心地位→次日更强预期上修→转债在当日重新定价。作者解释与研究归纳分别保留，不补记本人买债。

| 环节 | 这个分支应检查什么 |
|---|---|
| 适用与选择 | 事件有当前预期；正股较早封板并保持强度，同方向随后扩散，支持其次日被抢筹的预期。相关股只上涨几个点不具备相同前提。 |
| 参与 | 先判断次日预期为何比早盘更强，再检查债是否已反映、整理承接与可买价格；预判和等债自身确认是两个执行分支，量价突破不能替代前提。 |
| 兑现 | 交易次日预期的当日上修，可以当日兑现；预期已被明显提前反映、债转弱或失去承接时退出，不必等次日真的一字，也不只等正股开板。 |
| 失败 | 早封后反复打开、板块助攻消失、核心地位被替代；或前提仍在但债不跟、突破失败、预期已透支。是否隔夜另作决定。 |

**本例工具检查：** 保隆09:31一分钟线已收涨停，万丰09:45收涨停；10:35债开始价格确认，金盾等后续封板是后来追加信息，不能倒填早盘。广泰、声迅正股当日均未涨停，宽泛价格回放中的亏损与未触发原样保留，但不能作为这个完整分支的同条件失败。估值、历史敏感度及债市环境用于成本和弹性检查，早封地位及次日预期才是机会选择主线。明细见[模式案例](低空经济股债联动_20261016.md#早封时间怎样变成次日预期)与[限定样本回放](低空候选筛选_20261016.md)；同前提的跨日成功失败仍待补齐。

进一步的[量化定义与监控设计](早封核心转债_量化定义与监控优化.md)用排除自身后的队友强度、早封履历、债的独立确认和参与价上限，把这一分支对应到现有转债监控；次日预期先保留证据状态，不输出未经校准的一字概率。

保隆午后的[同步市场核对与监控重整](转债监控_事件Agent与市场风险优化.md)补充：13:10股市和转债基准已较午收走弱，债仍封板，13:30才出现本轮价格打开。市场环境应持续参与获利保护；事件Agent负责新消息及关系证据，行情和风险规则持续运行，不能只依赖个券破位。

## 八、共同执行：买入以后怎样检验原来的判断

[116课00:22—01:53、03:33—04:25](../课程笔记/116_几个例子.md)要求看到隔夜与次日的完整持有风险；[120课03:06—06:12](../课程笔记/120_一月极弱回顾.md)说明波动放大时旧支撑和做T习惯可能失效；[126课02:12—11:32](../课程笔记/126_环境适应与回撤心态.md)把环境适应与保留成果相连；[127课20:10—21:08](../课程笔记/127_标的方向与容量选择.md)讨论机会范围和精力损耗。

据此整理执行记录时，分别写实际成本、持有周期、总仓位、加减与回补、退出依据。做T叠加在原持仓与机会之上；增加同类股票数量也未必减少共同风险。

[K02兆易](K线与操作对照.md#k02)与[K10摩尔](K线与操作对照.md#k10)用于检查回补、加仓后继续下跌；[K01东山](K线与操作对照.md#k01)、[K08国芳](K线与操作对照.md#k08)、[K11容大](K线与操作对照.md#k11)用于比较买点、隔夜及退出。它们是执行证据，不另建“做T模式”。

新增[K17](K线与操作对照.md#k17)还保留同样科技修复中云南与东山的不同结果及下一交易日再跌；[K18](K线与操作对照.md#k18)保留事件修复后的退出。10/13另一只PCB买入自述为东材科技，未与10/9的东山混成一笔；股票、日期和每笔行为分别记录。

课程能提供需要重评的条件，尚未给出所有个股统一的止损幅度、补仓上限和固定持有天数。本文的失败检查用于检验原假设，不能宣称作者每次都按这些条件退出。
