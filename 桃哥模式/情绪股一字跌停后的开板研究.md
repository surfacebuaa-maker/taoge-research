# 情绪股一字跌停后的开板：预判、参与与次日退出

**这项研究要依次回答三个问题：前一天有没有理由重点观察次日开板；实际打开以后有没有值得参与的承接；按实际参与成本，次日有没有可兑现的退出。三个问题分别留证据、分别验证。**

## 一、课程先给出的判断：打开是一个环节，承接要有来源

### 1. 情绪连板股的修复，依赖市场与队友愿不愿意接

[122课10:46—18:38](../课程笔记/122_环境对手法的影响与独立结构.md)将克来、艾艾与联明放在不同环境中比较。16:02—18:04尤其解释联明此前继续涨停时，普路通、华生及华体等已经出现负反馈；后来的连续下跌，不能只从联明自己的K线理解。

这部分对本研究的作用是提供**参与约束**。课程并没有普遍推荐高位情绪股撬板；23:50—26:58还明确警惕弱环境中高位晋级失败后的参与。研究“打开后能不能做”，须保留“不参与”的分支。

**研究延伸：** 同一股票记录个体打开、同梯队压力及市场覆盖面三个状态。单个小盘ETF翻红只是一项价格代理，不能代替“全市场情绪已经恢复”；月份仅作历史分组，不写成固定买卖开关。

### 2. 同一天打开，时点和后续承接也可能完全不同

122课21:18—23:24及课件第11页，比较2024年3月5日的三例：

| 案例 | 课程中的观察 | 本轮历史对照 |
|---|---|---|
| 标准股份600302 | 竞价已打开，此前两个一字跌停，随后涨停 | 3/1、3/4全天一字；3/5开4.47、收5.09；3/6开4.83 |
| 天永智能603895 | 约10:46打开，尾盘明显修复 | 3/4全天一字；3/5开20.30、收23.80；3/6开21.68。5分钟首次出现高于跌停的价格落在10:45—10:50，不能称精确10:46 |
| 神驰机电603109 | 约11:02打开，尾盘重新跌停，次日有冲红 | 3/4全天一字；3/5开收均17.07，盘中确曾打开；3/6开16.77。5分钟只能定位11:00—11:05 |

**研究延伸：** “更早打开”是待检验特征，不直接设成必胜条件。分别记录竞价已经打开、盘中首次打开、再次回封及打开后能否抬高低点；不能把竞价打开和11点撬板统一按当日开盘价买入。

### 3. 封单与成交要一起看，预判也要允许不兑现

[123课21:14—22:36](../课程笔记/123_高低位极弱与压力判断.md)讨论春光及联明：卖压大、买入承接不足，会使本来预计打开的股票继续封住；有成交增加也未必马上打开。春光4/24仍是一字，4/25才不再全天一字。

这是课程复盘中的预期与实际差异，没有取得讲师4/23盘中的原始预测记录，不能写成一次已核验的实时预警失败。课程关于资金身份的归因也不转成程序事实。

**研究延伸：** 前一天预判只决定观察优先级；当天以实际成交确认打开。用户提出的“前一天封单可以帮助判断次日开板”是本研究要验证的核心假设，目前尚无历史封单序列支持数值阈值。

## 二、前一天：建立开板观察名单

第一层先确认股票属于哪个研究分支：情绪连板退潮、明确新增利空，或两者叠加。情绪股也可能同时有减持、财报、监管等信息，不按股票名称永久归类。ST及其他涨跌幅制度单列，本轮只处理正常交易的普通主板股票。

第二层再描述压力状态，所有字段按前一天收盘时已经知道的信息记录：

| 观察项 | 需要保存的证据 | 对次日观察的作用 |
|---|---|---|
| 一字履历与位置 | 连续一字日数、此前涨停梯队、相对起涨位置、从断板以来累计跌幅 | 区分首次核按钮与多日连续压力；跌得多不单独构成参与理由 |
| 剩余封单 | 固定时点的跌停价卖一未成交数量、金额、源时间与采集时间 | 描述尚未成交的卖压，不能用当天成交额代替 |
| 封单变化 | 同时刻跨日比较，及尾盘同价位数量的增减；金额和股数分列 | 避免跌停价格下降本身造成金额变小，被误认成卖压消退 |
| 相对承接规模 | 封单金额÷此前20日内非一字交易日的成交额中位数；封单股数÷当时已知流通股本 | 把绝对封单放回股票自身容量中理解；分母和披露日期必须可回查 |
| 实际买入承接 | 跌停价累计成交、临近尾盘成交是否持续；有逐笔时另拆新增卖单、撤单与成交 | 判断封单变小是否伴随真实成交；快照不能独立分解撤单 |
| 队友与环境 | 事前冻结的同梯队名单、新增与持续跌停、打开后回封、市场上涨覆盖面及小盘参照 | 检查是否仍有新的压力，不由一只股票改善推定情绪全面好转 |
| 新信息 | 公告日期、实际首次可见时间、事件内容及版本 | 避免盘后新增风险使原预判失效 |

这里的比例是**研究字段设计**，不是已验证的“低于多少就会开”公式。没有封单历史时输出“封单预判不可计算”，仍可留下带原因的观察名单。

本轮另请求公开跌停池接口的2024/3/4、4/24历史日期，均未返回对应历史数据，原始返回与[请求记录](../课程视频/情绪股一字跌停开板_20261018/历史封单尝试/请求记录.json)已保存。该结果只说明这次公开接口未提供所需历史，不等于证明市场上不存在可取得的历史封单资料。

封单变化可理解为同一价位未成交卖单库存的增减，受到新增委托、撤单和成交共同影响。隔夜后次日委托重新形成，前一天收盘封单不能直接当成次日竞价卖压。交易时段的撤单边界以交易所规则为准，见[样本期2023年规则](https://www.sse.com.cn/lawandrules/sselawsrules2025/repeal/rules/c/c_20250612_10824490.shtml)。

**预判验证的分母是每一个一字跌停观察日。** 一段连续三个一字的过程应留下三行，分别检查次日是否打开，不能只保留最后一天，把前两天的等待从记录里删掉。预测标签再拆为竞价打开、盘中打开及持续离开跌停；一次短暂成交高于跌停，不等于稳定打开。

## 三、开板当天：先确认打开，再检查参与价

### 1. 竞价与盘中打开分别处理

- **竞价成交价已经高于跌停价：** 记录9:25的成交结果、未匹配量与当时可用信息。若等9:30后才确认，不回填成自己买在竞价开盘价。
- **竞价仍在跌停价：** 看连续竞价中是否真正出现高于跌停价的成交。卖一封单变薄、出现大买单，都还只是观察线索。
- **只有5分钟线：** 本根最高价高于跌停，只能说明这5分钟内发生过打开；本根完成以前不能使用它的最终收盘、最低价和成交额。

### 2. 本轮比较两种参与代理

| 分支 | 完整K线确认条件 | 价格安排 |
|---|---|---|
| A：第一次完成线离开跌停 | 第一根完整5分钟收盘高于当日跌停价 | 下一根开盘作参考参与价 |
| B：多等一轮承接 | 连续两根完整5分钟收盘高于跌停价，后根低点不低于前根，且后根收盘更高；午休两侧不当成相邻5分钟 | 下一根开盘作参考参与价 |

两者最晚14:30确认，每段一字序列、每个分支只取一次初始确认；不因首次参与不顺而反复挑更好的触发。5分钟、两根、14:30均为研究者预先定义，课程未给出这些机械阈值。B只检验一种简化承接形态，没有覆盖所有回踩方式。

价格方案还要回答：从参考买价到**当时已知**的最近压力区域有多远，回封和新低意味着什么，确认时的队友是否继续恶化。若确认后已快速抬高成本，允许放弃；不能为了让盈亏比好看，将目标改成事后最高价。

本轮先验证A/B时序与次日价格，没有将尚未统一的压力位算法补成课程买点。下一根开盘已回到跌停价、已到涨停价、该根只有单一价或无量时，不确认成交。示例1万元不超过整根成交额1%的检查只作**事后容量诊断**，不声称开盘时已经知道整根成交额。

### 3. 当天回封，是持仓风险变化

已经买入的新仓位，若当天再次封死跌停，应记录回封、低点和市场恶化，进入隔夜风险状态。不能在回放里按当天止损价直接卖出新仓位，也不能因为次日后来修复，就把当天风险删除。

## 四、次日：退出条件围绕实际成本和可成交性

前一日的参与记录应已经保存成本、假设失效条件及计划退出时点。次日先核对新公告、竞价、队友和实际卖出条件，再按预先确定的分支评价。

| 情况 | 需要检查什么 | 研究处理 |
|---|---|---|
| 高开或出现早盘修复 | 相对实际成本的净空间，而不只是相对昨收是否翻红 | 比较按计划兑现与等待承接的差别，不能事后只选最高冲高 |
| 低开、首轮承接失败 | 首根完成线是否弱于开盘、是否跌破前根低点、队友是否新增压力 | 形成下一根执行的退出情景，保留跳空损失 |
| 再次跌停或没有可确认买盘 | 跌停卖出排队、打开时段及可能的成交量 | 标为退出受阻；不能按跌停开盘价自动记作卖出 |
| 走势强、选择继续等待 | 为什么持有、保护依据和最迟退出时间 | 超出次日退出研究范围的持有另记，不用后来涨幅改写原计划 |

本轮固定比较三种退出代理：X1次日09:30开盘参考；X2次日09:45固定时点；X3首根5分钟收盘不高于开盘则下一根退出，否则等首次收盘跌破前根低点，最晚10:00退出。它们是用于比较的研究分支，不是桃哥给出的统一纪律。

若目标执行根开盘仍在跌停价、整根单一价、无量或示例容量不足，程序不确认在该价退出，继续寻找后续符合条件的5分钟开盘；整日仍不满足则保留未退出及日末浮动。这个保守过程不能还原真实排队成交，也不声称找到真实最早可卖时刻。

2. **天永当天的拉升并没有完整留到次日。** 20.30开、23.80收，次日21.68开。是否参与在打开初期、尾盘还是更晚确认，决定隔夜能否承受这段回落；当天大阳线不能代替次日兑现。

4. **竞价已打开也可能继续跌。** 联明4/11开13.46、收12.80，次日开12.51；华生4/10小幅收于开盘之上，次日仍明显低开。打开日收阳、此前已经多个一字，都不足以单独支持参与。

## 七、分钟核查为什么阻止收益统计

共取得17个对象各88根日线，15个对象各2,880根5分钟线。14只股票的BaoStock与腾讯日线，1,232个股票日期、4,928个OHLC字段在0.011元容差内全部一致。

但11段序列的打开日及次日中，每段至少一日存在日线与分钟汇总量额差异，6段另有OHLC差异。例如天永3/5日线收23.80，5分钟末根收23.50；其日线最高24.79，分钟最高24.70。分钟日期及48根覆盖完整，也不代表价格已经可靠。

## 九、追加复核：分钟差异、封单来源与模式验证

### 1. 差异已经定位到哪里

**能确定的是：本次差异来自所取历史分钟数据的内容，不能通过改成交量单位、复权或本地聚合消除。天永3/5的分钟收盘明确没有反映15:00收盘竞价。其他价格与量额差异的内部生成原因，尚无提供方说明，不统一归因为漏竞价。**

| 排查项 | 本轮实际检查 | 得到的结论 |
|---|---|---|
| 本地汇总与请求范围 | 天永3/5—6重取5、15、30、60分钟；另逐日重取5分钟 | 新旧5分钟逐行一致，各周期汇总量额、最高与收盘一致，排除本地跨日拼接和只算错一个周期 |
| 复权 | 原请求均不复权，核对3/1—7调整事件为空 | 本例不能用除权解释23.80与23.50差异 |
| 日线本身 | 既有BaoStock与腾讯日线一致；新源40日分时末价逐分对比 | 40/40与日线收盘精确到分一致 |
| 股与手、四舍五入 | 通达信量按手×100换股，再对日线；BaoStock原字段按股 | 通达信40日最大绝对差49股；BaoStock天永3/5差-108,586股，普路通4/9差+541,068股，不能解释成固定100倍或普通舍入 |
| 分时时标错位 | 240点解释为09:31—11:30、13:01—15:00的分钟结束点，与12日原始HH:MM分笔交叉验证 | 有分笔可比的2,860点全部逐分同价；15:00点单独对应收盘竞价，未挪成14:59 |
| 分钟价格是否只差最后一笔 | 在同一5分钟结束时点比较1,920组价格 | 235组差至少1分，其中80组差超过1分，分布于17/40日；白天也存在差异 |

这里的“通达信”指公开行情节点`180.153.18.170:7709`的历史分时、历史分笔，由[Pytdx历史接口](https://pytdx-docs.readthedocs.io/zh-cn/latest/pytdx_hq/)读取。原始分时没有时戳、只有顺序价格和量，本轮时标是经分笔核对的解释。两项来自同一行情体系，分笔核对用于确认时标，不算第三个独立数据源。

**天永3/5是能直接说明竞价问题的一例：** 通达信分笔14:57有23.50元成交，15:00为23.80元、1,536手；分时末价及两套日线均为23.80。BaoStock末根却收23.50。最后5个分时点合计376,000股，BaoStock末根218,200股，相差157,800股，并不等于竞价153,600股；因此连本例的成交量也不能仅靠补一笔竞价修好。日线最高24.79，而BaoStock与通达信分笔最高均仅24.70，说明公开分笔也不能冒充完整逐笔价格，不能据此重建可靠的全部高低点。

成交量差异还有一个反证：多数核对日BaoStock汇总量反而大于日线，单纯“少算收盘竞价”不会产生这种方向。原数据继续保留，未按日线同比缩放每根量额、未将23.80强行覆盖末根后宣布整日修复。

| 前日剩余卖单 | 新补7个观察日的媒体近似金额 | 无原始时间、精确股数、撤单/成交分解，不能训练开板概率 |
| 历史分钟、竞价盘口 | 已连接高频工具明确仅支持当日日内L1，不支持历史、逐笔和盘口；本轮新增历史分钟0根 | 原B低点、X3低点、竞价未匹配卖量仍不能回溯验证 |
| 公告与资讯 | 能定位历史线索并回查原文；天永、华生分类更清楚 | 搜索空值或不匹配结果不能证明没有利空，不能保证事件清查完整 |

同花顺返回也需要逐项检查，本轮保留了四类实测问题：

- **成功但缺字段：** 请求历史卖一库存，返回了跌停价、流通A股及普通成交额，没有返回卖一封单。`success`不等于请求字段已满足，普通成交额继续单列。
- **历史条件混入最新价格：** 复杂一字筛选返回空；简化为3/4收盘跌停后返回7只，包括标准、天永、神驰，但跌停状态列标为20240304，收盘价列却标为20261016。历史状态可以作为候选核对线索，最新价格不得进入2024回放，空结果不作为“当日没有事件”。
- **量的参数与展示单位有歧义：** 首次四股查询参数写“万股”，单元格还带万/亿缩写；先拒收该批量字段，再明确单位参数为股重新取数，通过原量核对后才使用。
- **休市填值与当前简称：** 含单位补取的112条返回行中，38条属于休市日延续收盘价，按交易日历排除；只保留50个唯一完整交易日，其中40日用于原样本核对。当前简称ST标准不改变2024年原始`isST=0`记录。

[新增离线复核程序](../量化程序/limitdown_ifind_audit.py)分别输出40日日线、返回行检查、媒体封单、金额/股数变化及次日价格路径，留输入与源码哈希，不接账户或改动提醒。新增11项检查覆盖休市填值、列日期错配、单位歧义、重复冲突、伪封单替代与原协议哈希；量化目录43项测试通过，6份分析文件在另存目录复现逐字节一致。运行方法见[程序说明](../量化程序/README.md#同花顺mcp再复核)。

本轮16次MCP查询、3篇媒体原页面、新增天永公告及分析结果保存在[本地专项目录](../课程视频/情绪股一字跌停开板_20261018/同花顺MCP再研究/)；请求时间与归档时间分别记录，数据和凭据不进入Git。未重新看课或新增B站视频。

### 3. 请求成功不等于字段完整，短线统计需选择入口

初次普通浏览器客户端标识下，多项接口返回HTTP 200、`errcode=0`和空表。参照项目记录的Dalvik客户端标识后，同一历史分时与短线接口开始返回实际内容，证明本轮部分空表来自请求格式。全部测试均未携带用户身份、Token或第三方账户凭据。

- **最近交易日涨跌统计与天梯能取到。** 10/16统计含涨停61、跌停11、实际跌停10、上涨3301、下跌2127；另有12项连板统计数组和明确返回10/16的天梯名单。均是开盘啦口径，ST范围、分母、数组位置和重叠名单还须独立核查。
- **历史复盘可补环境，不能冒充跌停卖一。** 3/4复盘返回14个题材分组及`nums`，其中涨停73、跌停4；它不是跌停股票库存表。同日另一涨跌统计接口日期正确却缺`ZT/DT/SZJS/XDJS`等字段，不能按原读取器默认值填0。最近交易日炸板列表对照仍为空，不算已取得有效列表。
- **当前版本与历史标签分别核查。** 历史请求返回日正确，不保证每个题材标签都有历史版本；无源日期的当前休市快照也不自动认成10/18行情。
