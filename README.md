## 学习安排

1. 从第111课开始，先学习111—127课；优先使用有字幕的版本。
2. 每次学习复制[笔记模板](课程笔记/笔记模板.md)，以“课号_课程标题.md”命名。
3. 记录关键观点、案例时间点、自己的理解和待核对问题；不要把未观看的课程当作已学习。
4. 课程笔记保留逐课上下文；跨课程总结整理到“桃哥模式”的对应手法目录。

Git同步研究文档和课程笔记。课程视频、课件、字幕及分析素材仅保存在本地，不进入Git。
